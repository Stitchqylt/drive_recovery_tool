# Contributing to Drive Rescue

Thank you for your interest in contributing to **Drive Rescue**! We welcome bug reports, feature requests, documentation improvements, and code contributions.

## Getting Started

1. Fork the repository
2. Clone your fork
   ```bash
   git clone https://github.com/drive-rescue/drive-rescue.git
   ```
3. Create a feature branch
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes
5. Run the tests
   ```bash
   python tests/test_suite.py
   ```
6. Run the QA benchmark
   ```bash
   python tests/qa_benchmark.py
   ```
7. Submit a pull request

## Code Style

- Use standard Python 3.8+ conventions
- No third-party dependencies (pure stdlib)
- Follow existing code structure and naming patterns
- Update documentation when adding new features
- Keep functions small and focused

## Reporting Issues

Please use the GitHub issue tracker to report bugs or request features.

## Security Issues

Please report security vulnerabilities to security@drive-rescue.dev
